# Internship Task 1 - PHP & MySQL Environment Setup

This repository contains the basic setup for the ApexPlanet Web Development Internship.

## What’s Included

- PHP local development environment using XAMPP
- Simple `index.php` file
- Git version control setup

## How to Run

1. Start Apache server from XAMPP Control Panel.
2. Visit `http://localhost/internship-task1` in your browser.
